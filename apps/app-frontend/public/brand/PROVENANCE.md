The application and package mark is exported from the owner's Figma node `3:1175` in file `nxRBVO5kqVue97M5fgKDvZ`. `apps/app/icons/figma-mark.svg` and `apps/app-frontend/public/figma/2927a.svg` are byte-identical copies. The PNG and ICO files under `apps/app/icons` are rasterizations of that vector for operating-system packaging.

The former hand-authored geometric U logo and its old README SVG banners were removed from the current tree. README PNGs are composed by `scripts/build-readme-graphics.py` using only the Figma mark, colors from `apps/app-frontend/src/figma.css`, the bundled Geologica font and a screenshot captured from running Tauri. Their source, dimensions and limitations are recorded in `docs/GRAPHICS_AUDIT.md`. No generated image model or external picture service is used.
