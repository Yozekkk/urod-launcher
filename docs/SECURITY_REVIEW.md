# Security review in progress

Date: 2026-10-19. This is a repository review and deterministic test record, not a penetration-test certificate.

- `apps/app/capabilities/main.json` grants the main window core permissions and autostart actions. It does not grant broad filesystem, shell, HTTP or updater plugin capabilities. The sign-in window has no native IPC capability.
- `apps/app/tauri.conf.json` sets a restrictive CSP; only self, IPC, data images, and Modrinth CDN images are permitted for the relevant resource types. Inline styles remain enabled for the current UI.
- Native skin import limits the PNG to 1 MiB, decodes it with image allocation limits, requires 64×32 or 64×64 pixels, and confines the filename to a parsed UUID under the library directory. The skin index is persisted through a temporary file and rename.
- In-place skin replacement uses the same native PNG validation, writes a staging file in the library directory and atomically renames it over the existing UUID path. If the catalog write fails, it attempts to restore the previous validated bytes. Saved skin reads reject symlink files. A native malformed-PNG request left the record unchanged, and a Unix test verifies symlink rejection. A crash between texture replacement and catalog persistence could still leave the new valid texture with old metadata; transaction recovery remains an open review item.
- Microsoft skin upload sends the token from the native account session and checks the returned profile id, active variant, and texture host before reporting success. The user interface displays a native error when the service rejects the operation. Live upload has not been exercised with an owner account.
- GitHub updates require a matching size and SHA-256 and Tauri signature verification. The UrodLauncher public key and endpoint are unset, so automatic updates stay disabled. No inherited NCreate key is used.
- The existing Minecraft engine has deterministic tests for path confinement, hash checks, cancellation, rollback, modpack import traversal, Java runtime validation, and process lifecycle. These do not replace live installer and launch checks.
- Java paths saved for individual major versions are bounded to 16 entries and 4096 bytes per path, and each executable is probed and checked against its declared major before persistence. Launch-time selection reuses the engine's Java validation; a pack-specific path takes priority and a global default is not written into pack metadata.
- The pack Java detection command accepts an instance id, resolves that pack's required major through the engine, and returns only a runtime already validated by Java discovery. The UI does not persist the result until Save; disabling the switch clears the pack override. Pack launch command and environment inputs remain disabled, so this change does not introduce a shell execution path.
- The selected-pack log command checks the instance id, confines the log directory to that instance, rejects symlink directories and files, and returns at most the latest 32 KiB. Game stdout/stderr capture removes the active access token; the offline placeholder `0` is treated as public to avoid corrupting version numbers. Before frontend delivery, common named credential fields are redacted. Arbitrary mod-generated prose can still contain unrecognized secrets, so this is bounded exposure rather than a guarantee that all secrets are removed.
- Global and per-pack window dimensions are either both unset or a pair within 320–7680 by 240–4320. The engine selects the pack pair first, then the global pair; it adds numeric `--width`/`--height` arguments directly to the child process vector and replaces any existing resolution arguments without invoking a shell. Fullscreen and arbitrary command fields remain disabled until they can be implemented without damaging pack options or executing unchecked commands.
- Download parallelism is stored as a bounded integer from 1 to 10, used to construct the engine's semaphore after restart. The backup-folder command accepts no frontend path, checks the invoking main window, rejects a symlink/non-directory `backups` entry, and opens only the canonical child of the launcher data directory. A temporary symlink to `/tmp` in the isolated QA data was rejected and removed. The command does not create database backups; existing migration backups remain the only files expected there. The independent write-limit control is disabled.
- `pnpm audit --audit-level high --prod` initially found [GHSA-68fv-2mgg-jv7q](https://github.com/advisories/GHSA-68fv-2mgg-jv7q) in transitive `source-map-js` 1.2.1. The workspace now overrides it to patched 1.2.2; a fresh `pnpm audit --prod` reports no known production advisories. This is a point-in-time registry result, not a guarantee against undisclosed flaws.

Open review items: audit every Tauri command argument after the remaining UI work; exercise path and network failures against real packages; verify operating-system keyring behavior on Windows and Linux; run dependency and license scans for the final lockfiles; inspect install/uninstall and signed update recovery. Do not publish a Stable claim while these are open.
